# ADR-003: Database — PostgreSQL 15 + Redis

## Status
Accepted

## Context
Доменная модель содержит строгие связи: User → Entry → Rating/Media, User → Category, User → WeeklyReport. Требуется ACID для транзакций (Entry + Rating + Media сохраняются атомарно). Нужна поддержка JSONB для гибких полей (reminder_days). Budget $0-10/mo, pet project, max 100 users.

## Decision
Использовать **PostgreSQL 15** как primary database + **Redis** для cache и Celery broker.

## Consequences
### Positive
- **ACID** — гарантированная целостность при cascade транзакциях (Entry creation).
- **JSONB** — гибкость для `reminder_days` и `changed_fields` snapshots без schema migration.
- **JSONB** — гибкость для `reminder_days` и `changed_fields` snapshots без schema migration.
- **SQLAlchemy 2.0 async** — полноценный ORM с PostgreSQL-специфичными фичами.
- **Alembic** — reversible migrations, version control schema.
- **Redis** — lightweight cache для read models (DailyHistory, WeeklySummary) и Celery broker.
- **Бесплатно** — PostgreSQL и Redis входят в Docker Compose на VPS.

### Negative
- **Schema migrations** — при изменении моделей нужно писать Alembic миграции (но это best practice).
- **Vertical scaling** — при росте > 1000 пользователей может понадобиться read replicas (не критично для MVP).

## Alternatives Considered
- **MongoDB** — rejected. Нет ACID транзакций для multi-document updates (Entry + Rating + Media). Меньше знаком solo-разработчику. SQLAlchemy не поддерживает MongoDB.
- **SQLite** — rejected. Не подходит для concurrent writes (Telegram bot + Mini App API + Celery workers одновременно). Нет JSONB, нет timezone-aware types.
- **MySQL** — rejected. PostgreSQL имеет лучшую поддержку JSONB, CTE, window functions (для streak calculation и трендов). Solo-разработчик предпочитает PostgreSQL.
- **Amazon RDS / Cloud SQL** — rejected. Платные managed сервисы, выходят за бюджет $0-10/mo.

## Compliance
- GDPR: PostgreSQL поддерживает row-level security (RLS) если понадобится в будущем. JSONB позволяет хранить audit snapshots без schema changes.
- Data residency: VPS выбирается разработчиком (Hetzner EU или DigitalOcean), соответствует GDPR.
