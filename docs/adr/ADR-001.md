# ADR-001: Frontend Framework — React 18 + Vite SPA

## Status
Accepted

## Context
SkillTracer — это Telegram Mini App (встроенное веб-приложение в WebView). Требования:
- Мобильный-first UI с календарём, графиками, формами ввода.
- Быстрая загрузка в WebView (желательно < 2 секунд).
- Не нужен SEO/SSR — приложение полностью аутентифицированное, работает внутри Telegram.
- Solo-разработчик знает React-экосистему.
- Бюджет $0-10/мес не позволяет платить за SSR-хостинг или edge-функции.

## Decision
Использовать **React 18 + Vite SPA**.

## Consequences
### Positive
- **Vite** даёт мгновенный HMR и оптимизированные бандлы — критично для WebView.
- **React 18** — зрелая экосистема, множество библиотек (Zustand, react-hook-form, react-i18next).
- **SPA** без SSR снижает сложность: нет hydration, нет server-side routing, нет edge-функций.
- **Tailwind CSS** — utility-first, быстрая стилизация компонентов без CSS-in-JS overhead.
- **Zustand** — минималистичный state manager, нет boilerplate Redux.

### Negative
- **Нет SSR** — не влияет на продукт, т.к. Mini App не индексируется.
- **Нет file-based routing** — нужен `react-router-dom` или ручной роутинг (BottomNav + 4 страницы).
- **SEO = 0** — irrelevant для Telegram-бота.

## Alternatives Considered
- **Next.js** — rejected. SSR overhead не нужен для WebView, требует Node.js бэкенд (VPS стоит дороже), file-based routing избыточен для 4-5 страниц.
- **Vue 3 + Vite** — rejected. Хороший фреймворк, но solo-разработчик имеет больше опыта в React-экосистеме. Переключение стека увеличит время на 20-30%.
- **Svelte** — rejected. Меньшая экосистема, сложнее найти библиотеки для i18n и charts.

## Compliance
- GDPR: SPA не хранит cookies, аутентификация через Telegram initData (no PII in localStorage).
- Performance: LCP target < 2.0s достижим благодаря Vite + lazy loading.
