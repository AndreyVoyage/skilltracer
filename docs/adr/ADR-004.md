# ADR-004: Auth Strategy — Telegram OAuth only (initData HMAC)

## Status
Accepted

## Context
Все пользователи — пользователи Telegram (создатель + 2 друга). Нет веб-аутентификации вне Telegram. Mini App получает `initData` от Telegram WebView. Бюджет $0-10/mo, нет средств на Auth0/Firebase Auth. Solo-разработчик хочет минимум complexity.

## Decision
Аутентификация **только через Telegram OAuth (initData HMAC validation)**. Никаких паролей, никаких JWT в localStorage.

## Consequences
### Positive
- **Нулевая стоимость** — Telegram предоставляет аутентификацию бесплатно.
- **Seamless UX** — пользователь не вводит пароль, просто нажимает "Открыть Mini App".
- **Нет password management** — не нужен bcrypt, reset password, email verification.
- **Безопасность** — HMAC-SHA256 validation initData гарантирует, что данные пришли из Telegram. Нет риска утечки паролей.
- **Нет localStorage для токенов** — избегаем XSS + token theft.

### Negative
- **Vendor lock-in** — пользователи могут входить только через Telegram. Если Telegram заблокирован/недоступен — продукт не работает (acceptable для pet project).
- **No web auth** — нельзя открыть Mini App в браузере без Telegram (by design).
- **initData expiry** — initData валиден ограниченное время (но это handled Telegram WebView автоматически).

## Alternatives Considered
- **JWT + пароль** — rejected. Увеличивает attack surface (password leaks, brute force, reset flows). Нет необходимости: все пользователи уже в Telegram.
- **Hybrid (Telegram + JWT)** — rejected. Избыточная сложность. Telegram initData уже содержит `auth_date` и `hash`, можно проверять на каждом запросе без JWT.
- **Firebase Auth / Auth0** — rejected. Платные tiers, выходят за бюджет. Overkill для 3 друзей.
- **Magic links via email** — rejected. Не нужен email для Telegram-пользователей. Увеличивает friction.

## Compliance
- GDPR: Telegram обрабатывает authentication; SkillTracer не хранит пароли. Минимизация PII (только telegram_id, username, first_name).
- Security: HMAC validation — единственный trust boundary. Rate limiting на auth endpoint защищает от brute force initData guessing.
