# ADR-005: Hosting & Infrastructure — VPS + Docker Compose

## Status
Accepted

## Context
Pet project для 3 друзей, max 100 concurrent users. Бюджет $0-10/мес. Нужно запустить: FastAPI backend, PostgreSQL, Redis, Celery worker(s), aiogram bot, React SPA (static files). Нет DevOps команды, solo-разработчик управляет инфраструктурой.

## Decision
Использовать **VPS (Hetzner / DigitalOcean) с Docker Compose**.

## Consequences
### Positive
- **Стоимость** — Hetzner CX11 ~$4-5/мес, DigitalOcean droplet ~$6/мес. Вписывается в бюджет.
- **Полный контроль** — root доступ, можно настроить backups, monitoring, SSL.
- **Docker Compose** — декларативный стек, легко поднять на staging и production.
- **Nginx / Traefik** — reverse proxy + SSL termination + static file serving.
- **Нет vendor lock-in** — можно мигрировать на другой VPS за 30 минут.
- **PostgreSQL + Redis** — запускаются в Docker, данные на persistent volume.

### Negative
- **Manual server management** — обновления ОС, security patches, мониторинг диска — на разработчике.
- **No auto-scaling** — при росте > 1000 пользователей нужно будет мигрировать на managed services (acceptable для MVP).
- **Single point of failure** — один VPS, нет HA кластера (acceptable для pet project).
- **Backup responsibility** — daily pg_dump настроен через cron + Celery.

## Alternatives Considered
- **Railway / Render** — rejected. Managed PaaS, удобный deploy, но стоимость растёт с использованием. Для persistent PostgreSQL + Redis + workers может выйти > $10/мес. Меньше контроля.
- **Vercel + Serverless Functions** — rejected. Не подходит для persistent Python backend + PostgreSQL + Celery. Serverless не держит long-running bot polling.
- **AWS ECS / GCP Cloud Run** — rejected. Overkill для pet project. Сложность настройки, возможные unexpected costs. Нет в known tech stack.
- **Heroku** — rejected. Убрали бесплатный tier. Дорого для hobby.

## Compliance
- GDPR: VPS выбирается в EU (Hetzner Germany / Finland), что соответствует data residency.
- Security: SSL via Let's Encrypt (Nginx/Traefik). Daily backups минимизируют риск data loss.
