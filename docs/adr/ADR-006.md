# ADR-006: AI Integration — Explicitly Excluded

## Status
Accepted

## Context
Функционал SkillTracer:
- Ежедневный ввод: оценки 1-5, комментарии, медиа.
- Генерация отчётов: PNG-инфографика (Pillow) и видео 9:16 (ffmpeg).
- Социальный шеринг: Telegram native share.
- Мотивация: стрик, напоминания, красивый визуальный результат.

Нет use case для LLM: тексты отчётов — шаблонные ("Твоя неделя: 4.2/5"), нет чат-бота с генерацией текста, нет RAG, нет summarization. Монетизация = $0, нет бюджета на OpenAI API.

## Decision
**Исключить AI/LLM интеграцию** из MVP и Phase 2/3. Генерация отчётов — deterministic (Pillow + ffmpeg).

## Consequences
### Positive
- **Zero AI cost** — нет расходов на OpenAI/Anthropic API tokens.
- **Deterministic output** — отчёт всегда выглядит предсказуемо, нет hallucinations.
- **No prompt injection risk** — не нужно защищать от jailbreak, не нужен prompt engineering.
- **No data leakage** — пользовательские данные (дневниковые записи) не отправляются наружу.
- **Simpler architecture** — нет AI gateway, нет vector store, нет embedding pipeline.
- **Faster generation** — PNG рендерится за < 2 минут без сетевых вызовов.

### Negative
- **No "smart" insights** — отчёт не содержит AI-generated анализ («Ты лучше всех спал в среду»). Но это не требуется пользователями ( Discovery: "красивый отчёт", не "умный отчёт").
- **No chat interface** — нельзя спросить бота "Как я спал на прошлой неделе?". Но это не входит в JTBD.

## Alternatives Considered
- **LLM for report text generation** — rejected. Нет value proposition. Добавит latency, cost, complexity. Шаблонный текст + агрегированные данные достаточны.
- **RAG for personal insights** — rejected. Нет vector store, нет необходимости в semantic search по дневниковым записям.
- **Fine-tuned model for emotion analysis** — rejected. Оверкилл для pet project. Оценки 1-5 уже являются структурированной эмоциональной метрикой.
- **Future AI addition** — possible в Phase 4+ если появится бюджет и use case, но MVP явно исключает AI.

## Compliance
- GDPR: Пользовательские данные не покидают инфраструктуру. Нет third-party AI provider agreements.
- Transparency: Пользователи могут быть уверены, что их дневниковые записи не используются для обучения моделей.
